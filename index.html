Why scanning needs checking

QR code scams work because nobody can read a QR code

Criminals stick their own code over the real one on a parking meter, a restaurant table or a delivery notice. You scan, a login page opens, and it looks exactly right. The technique has a name now — quishing — and the only defence is reading the address before the page loads. That is what a QR code scanner should do, and almost none of them do it.

Questions

QR codes, answered plainly

Is this QR code generator really free?

Yes, and there is no account, watermark, scan limit or expiry. The generator runs in your browser using your own device, so it costs us nothing to let you use it.

How do I know if a QR code is safe to scan?

You cannot tell by looking — that is the whole problem. Use a scanner that shows you the address and checks it before opening. Paste any link into the checker at the top of this page to see the kind of findings TrustScan reports on your phone.

What is the difference between a static and a dynamic QR code?

A static code contains the destination itself and works forever. A dynamic code contains a link to someone else's server, which then forwards you — so it can be edited later, but it can also be repointed, tracked, or switched off when that company disappears. Every code made here is static.

Can I make a Wi-Fi QR code for guests?

Yes. Choose Wi-Fi in the generator, enter the network name, password and security type, and print the result. Guests point a camera at it and join without you reading a password out loud.

Can I create a QR code for my business card?

Choose Contact card. It produces a vCard containing your name, company, phone, email, website and address, which saves straight into the phone's contacts app when scanned.

Do QR codes expire?

Static ones do not. A printed QR code from this site will still work in ten years, because the information is in the pattern itself rather than on a server that has to stay online.

Can I put a logo in the middle of a QR code?

Yes — free, right here in the browser. Use the logo generator, set error correction to Highest, and keep the logo clear of the three corner squares. The app does it too, with a 2,400 px export.

Does the app work without an internet connection?

Yes. Scanning, generating and all 21 safety checks work with no connection at all, because none of it depends on a server.
